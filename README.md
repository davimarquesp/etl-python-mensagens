# Dashboard de Vendas no Excel

Este projeto tem como objetivo a criação de um dashboard de vendas utilizando o Microsoft Excel,
transformando dados brutos em informações visuais para apoiar a análise de desempenho.

## 📊 Dados Utilizados
Base de dados fictícia contendo:
- Produto
- Categoria
- Região
- Quantidade vendida
- Valor unitário
- Total da venda

## 📈 Dashboard
O dashboard apresenta:
- Indicador de total de vendas
- Gráfico de vendas por produto

## ▶️ Como visualizar
1. Faça o download do arquivo `dashboard_vendas.xlsx`
2. Abra no Microsoft Excel
3. Acesse a aba **Dashboard**

## 🛠 Ferramenta
- Microsoft Excel
